# 项目上下文

## 1. 基本信息

```yaml
名称: m-deeplx-vue
描述: 面向 uTools / ZTools 的多引擎智能翻译插件，支持文本翻译、截图 OCR 翻译和多语言界面
类型: 桌面插件（uTools / ZTools） / Vue 单页应用
状态: 开发中
```

## 2. 技术上下文

```yaml
语言: JavaScript、Vue SFC
框架: Vue 2.6 + Vue Router 3 + Vuex 3
包管理器: npm
构建工具: Vue CLI 5（Webpack）
```

## 3. 项目概述

### 核心功能
- 文本翻译：支持 DeepLX、DeepL Official、DeepSeek、Google API、Google Free、OpenAI 多种引擎。
- 智能截图翻译：通过 uTools 截图、Google Vision OCR 和 Google Translate 完成图片文字翻译。
- 本地设置管理：保存 API 地址、Token、模型、界面语言、图片翻译目标语言等配置。
- 平台集成：支持通过 uTools 或 ZTools 的插件指令/选中文本进入应用，并提供复制、隐藏、模拟输入等动作。
- 多语言界面：应用内置中英文文案，通过 Vue I18n 切换。

### 项目边界
```yaml
范围内:
  - 在前端界面中组织多种翻译 API 的调用参数和返回结果展示
  - 使用 uTools / ZTools preload 暴露的全局方法访问剪贴板、本地存储、截图和通知能力
  - 处理截图 OCR、文本翻译、结果回填和常用快捷动作
范围外:
  - 自建后端代理或服务端密钥托管
  - 自动化测试、端到端测试体系
  - 完整的安全隔离和凭据加密管理
```

## 5. 当前约束（源自当前代码现状）

| 约束 | 原因 | 决策来源 |
|------|------|---------|
| 运行时通过 `public/preload.js` 统一桥接 `window.utools` 与 `window.ztools` | 文本复制、截图、存储、通知和插件入口需要兼容双平台 API | ztools-compat 实施（2026-05-06） |
| 前端仍基于 Vue 2 / Vue CLI 5，未使用 Vue 3 组合式 API | 入口、路由、store 和 Element UI 组件体系均建立在 Vue 2 生态上 | 代码现状（2026-05-06 扫描） |
| 翻译调用主要直接从前端请求第三方 API | `HomeView.vue` 直接构造多家翻译接口请求，未经过统一 service 层 | 代码现状（2026-05-06 扫描） |
| 自动化验收依赖本地安装前端工具链 | 当前仓库缺少 `node_modules`，无法直接执行 `vue-cli-service lint` | ztools-compat 验收（2026-05-06） |
